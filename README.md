# DORA RoI Toolkit

A Python toolkit for working with the **DORA Register of Information (RoI)** under Regulation (EU) 2022/2554 and the ESAs Implementing Technical Standards on the RoI templates.

## Goals

- Typed data model for all RoI templates (B_01.01 – B_07.01)
- Field-level and cross-template validation with clear reports
- Import from Excel/CSV, best-effort export to xBRL-CSV for supervisory submission
- Concentration-risk analytics for ICT third-party dependencies
- CLI and a lightweight web UI
- Synthetic sample data for testing and demos

## Status

🚧 Early development. Not an official tool and not legal or regulatory advice. Always verify against the current ITS, EBA taxonomy and your competent authority's guidance.
